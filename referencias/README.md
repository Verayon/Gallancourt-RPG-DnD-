# Referências de design/UI

Capturas de tela e exemplos externos que servem de inspiração para como construir telas ou
tabelas do site — diferente de `fontes/`, que guarda o material de lore da campanha fornecido
pelo autor. Nada aqui é publicado: é só material de consulta para quando formos implementar algo
parecido.

```
referencias/
└── imagens/    Prints de UI, tabelas, layouts de referência
```
