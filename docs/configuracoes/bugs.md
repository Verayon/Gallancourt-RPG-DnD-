# Bugs reportados

Qualquer pessoa pode reportar um bug pelo botão "🐞 Reportar bug", visível no canto inferior
direito de toda página do site. Cada bug fica "Aguardando" até alguém investigar, corrigir e
testar a correção — para isso, peça a um agente (o Claude Code) para processar os bugs em
aberto; ele pode consultar e atualizar esta lista pelo [Painel do Mestre](/bugs){ .md-button .botao-painel target=_blank title="Abre o Painel do Mestre — ele precisa estar rodando no seu computador" }.
Depois de corrigido e testado, o bug passa para "Resolvido", com uma nota do que foi feito.
