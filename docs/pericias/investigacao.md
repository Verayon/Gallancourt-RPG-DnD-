# Investigação

Mede sua capacidade de analisar pistas e deduzir conclusões a partir delas — onde está um
compartimento secreto, qual arma causou um ferimento, qual é o ponto fraco de uma estrutura.

## Quando usar

- Procurar e interpretar pistas numa cena de crime ou ruína.
- Deduzir como um mecanismo ou armadilha funciona a partir de seus componentes.
- Reconstruir os eventos que levaram a uma situação atual a partir de evidências físicas.
