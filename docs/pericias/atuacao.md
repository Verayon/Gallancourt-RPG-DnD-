# Atuação

Mede sua capacidade de entreter uma audiência com música, dança, teatro, contação de histórias ou
outra forma de divertimento.

## Quando usar

- Tentar ganhar a simpatia (ou a moeda) de uma multidão com uma apresentação.
- Disfarçar uma mensagem ou sinal dentro de uma performance.
- Manter uma audiência distraída enquanto outra coisa acontece em segundo plano.
