# Percepção

Mede sua consciência geral do ambiente através dos sentidos e a agudeza com que você nota
detalhes.

## Quando usar

- Notar uma criatura escondida, uma armadilha ou uma porta secreta.
- Ouvir uma conversa através de uma porta, ou passos se aproximando.
- Perceber que algo está errado num ambiente (um objeto fora do lugar, um cheiro estranho).

!!! info "Percepção Passiva"
    Além do teste ativo, cada personagem tem uma Percepção Passiva (10 + modificador de
    Sabedoria + proficiência, se tiver) usada pelo mestre sem rolar dados, para notar coisas sem
    que o jogador esteja procurando ativamente por elas.
