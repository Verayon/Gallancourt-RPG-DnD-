# Sessões

Uma página por sessão, com o roteiro de preparação: resumo, NPCs e fichas de combate, cenas,
recompensas e pistas, lugares e o segredo do Mestre — cada parte em uma aba.

!!! tip "Criar uma sessão nova"
    O botão **Nova sessão** abre o [Painel do Mestre](../painel.md), que cria a página com o mesmo
    layout das anteriores e a adiciona ao menu. O Painel precisa estar rodando no seu computador
    (`admin\iniciar-painel.bat`). Depois de jogar a sessão, registre o que aconteceu no
    [Diário de Sessões](../../diario/index.md).
