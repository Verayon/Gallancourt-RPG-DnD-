# Sessões

Uma página por sessão, com o roteiro de preparação: resumo, NPCs e fichas de combate, cenas,
recompensas e pistas, lugares e o segredo do Mestre — cada parte em uma aba.

!!! tip "Criar uma sessão nova"
    O formulário abaixo cria a página com o mesmo layout das anteriores e já deixa escolher, em
    tabelas filtráveis, os NPCs/Jogadores/Lugares já cadastrados para esta sessão, mais um campo de
    texto livre com como você imagina a sessão (salvo como anotação na aba Resumo — ainda sem
    geração automática por IA). Precisa do [Painel do Mestre](../painel.md) rodando no seu
    computador (`admin\iniciar-painel.bat`). Depois de jogar a sessão, registre o que aconteceu no
    [Diário de Sessões](../../diario/index.md).
