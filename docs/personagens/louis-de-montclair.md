# Louis de Montclair

<div class="ficha" markdown>

| | |
|---|---|
| **Título** | Mestre |
| **Organização** | [Guilda dos Construtores Navais](../faccoes/guilda-dos-construtores-navais.md) (líder) |
| **Cidade** | [Baie de l'Éclair](../cidades/baie-de-l-eclair.md) |

O respeitado líder da guilda dos construtores navais. Artesão orgulhoso, despreza a brutalidade
de [Jean Vigny](jean-vigny.md), mas está preso a ele em uma relação simbiótica: a imprudência de
Vigny e a ameaça pirata garantem uma demanda constante por seus caros navios.

!!! warning "SEGREDO"
    Louis busca secretamente um patrono alternativo para se livrar do Comodoro.

!!! tip "Não confundir"
    Com Louis d'Aubren, o príncipe herdeiro executado, nem com a cidade de
    [Montclair de Lune](../cidades/montclair-de-lune.md).
