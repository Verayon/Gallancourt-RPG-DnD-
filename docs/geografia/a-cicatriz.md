# A Cicatriz

<div class="ficha" markdown>

| | |
|---|---|
| **Tipo** | Região / campo de batalha |
| **Localização** | Planícies próximas a [Saint-Armand](../cidades/saint-armand.md) |
| **Origem do nome** | [Batalha da Cicatriz](../eventos/batalha-da-cicatriz.md) |
| **Função atual** | Referência da fronteira entre a Aliança e L'Ordre |

</div>

**A Cicatriz** é a região das planícies próximas a Saint-Armand marcada por uma das batalhas
mais devastadoras da guerra civil.

Tornou-se não apenas uma marca física na paisagem, mas também uma fronteira simbólica. Depois
da guerra, passou a servir como uma das principais referências da separação territorial entre
a antiga Gallancourt ([Aliança dos Lordes](../faccoes/alianca-dos-lordes.md)) e
[L'Ordre de Célestien](../faccoes/l-ordre-de-celestien.md).

A Cicatriz permanece como lembrança física do conflito — a fronteira como memória.
