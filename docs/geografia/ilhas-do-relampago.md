# Ilhas do Relâmpago

<div class="ficha" markdown>

| | |
|---|---|
| **Tipo** | Região insular / arquipélago |
| **Localização** | Espaço marítimo próximo à região de Gallancourt |
| **Cor no mapa** | Azul-acinzentado |
| **Ligação principal** | [Baie de l'Éclair](../cidades/baie-de-l-eclair.md) |

</div>

!!! info "Leitura cartográfica"
    As Ilhas do Relâmpago são conhecidas pelo mapa regional, onde aparecem destacadas em
    azul-acinzentado.

As ilhas estão associadas ao espaço marítimo próximo a Gallancourt. Dentro da ambientação,
relacionam-se especialmente com a importância naval de Baie de l'Éclair e com as rotas
marítimas da região.

A presença de ilhas, canais e áreas costeiras ajuda a explicar por que o poder naval foi tão
importante durante a guerra civil.
