# Guerra Fria

<div class="ficha" markdown>

As décadas seguintes à guerra civil não trouxeram uma verdadeira paz. A guerra havia terminado,
mas ninguém havia esquecido como ela começou. A paz existe apenas porque ambos os lados sabem o
preço de uma nova guerra.

## O equilíbrio atual

| A Aliança dos Lordes possui | L'Ordre possui |
|---|---|
| força naval | unidade religiosa |
| produção agrícola | autoridade teocrática |
| poder econômico | território oriental consolidado |
| capacidade militar | controle das cidades associadas à nova doutrina |
| conhecimento arcano | liderança centralizada em Severin Marceau |
| redes de comércio e espionagem | |

Nenhum dos dois lados possui condições simples de eliminar o outro. Por isso, a guerra aberta
foi substituída por uma disputa silenciosa:

> Navios desaparecem. Informações são compradas. Famílias fazem acordos secretos. Mercadores
> financiam operações políticas. Nobres conspiram. Clérigos observam as fronteiras. Militares
> desconfiam dos próprios oficiais.

E, nas cidades, a população tenta reconstruir uma vida normal sobre as ruínas de uma guerra que
ainda não terminou verdadeiramente.
