# Monstros

Catálogo de criaturas do Manual dos Monstros (SRD) — cada uma com a ficha de combate completa
na própria página (CA, PV, atributos, ações...), vinda do banco de dados. A leitura é livre para
qualquer um; para criar variantes (ex.: Goblin → Arqueiro) ou editar equipamento/habilidades,
entre em **🔑 Modo Mestre** (cabeçalho, ao lado do alternador claro/escuro) — os controles de edição aparecem direto
na página de cada monstro.
Use a busca abaixo para filtrar por nome; o filtro de Tipo/Alinhamento ajuda a achar criaturas
por categoria.
