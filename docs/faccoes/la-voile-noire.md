# La Voile Noire

<div class="ficha" markdown>

| | |
|---|---|
| **Tipo** | Rede criminosa clandestina |
| **Sede** | Docas de [Dodixie](../cidades/dodixie.md) |
| **Líder (atribuído)** | [Zepharion](../personagens/zepharion.md), tiefling |

</div>

Nas sombras das docas de Dodixie existe uma terceira força, ao lado das casas Corbeau e Duvant:
**La Voile Noire**. Sua liderança é atribuída a Zepharion, que mantém uma vida pública enquanto
opera a rede.

Sua presença sugere uma camada de poder informal que pode afetar comércio, docas e política.
