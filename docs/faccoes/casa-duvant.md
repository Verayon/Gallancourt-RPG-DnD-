# Casa Duvant

A Casa Duvant reconhece a liderança da [Casa Corbeau](casa-corbeau.md), mas possui interesses
próprios dentro de Dodixie. A relação entre as duas é de **cooperação e competição**; Duvant não
se reduz a uma extensão de Corbeau.
