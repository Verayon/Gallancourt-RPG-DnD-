# Adepto Elemental

Suas magias dominam um elemento a ponto de superar resistências e extrair o máximo de cada dado de dano.

## Efeito

Ao obter este dote, escolha um tipo de dano: ácido, frio, fogo, elétrico ou trovejante. Magias que você conjura ignoram resistência ao tipo de dano escolhido. Além disso, quando você rola dano para uma magia que conjurar e que causa dano desse tipo, pode tratar qualquer resultado 1 em um dado de dano como se fosse 2.

Você pode escolher este dote várias vezes. Cada vez que o fizer, deve escolher um tipo de dano diferente.
