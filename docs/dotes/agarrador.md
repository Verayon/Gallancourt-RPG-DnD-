# Agarrador

Você desenvolveu as técnicas necessárias para dominar um adversário em combate agarrado.

## Efeito

Você desenvolveu as habilidades necessárias para se sair bem em combate agarrado a curta distância. Você ganha os seguintes benefícios:

- Você tem vantagem em jogadas de ataque contra uma criatura que você esteja agarrando.
- Você pode usar sua ação para tentar imobilizar uma criatura agarrada por você. Para isso, faça outro teste de agarrão. Se for bem-sucedido, você e a criatura ficam ambos impedidos até que o agarrão termine.
