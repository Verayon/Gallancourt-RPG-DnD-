# Adepto em Combate

Você aprendeu técnicas de combate marcial que lhe permitem executar manobras especiais em batalha.

## Efeito

Você tem treinamento marcial que lhe permite realizar manobras de combate especiais.

- Você aprende duas manobras à sua escolha entre aquelas disponíveis para o arquétipo Mestre de Batalha da classe Guerreiro. Se uma manobra que você usa exige que seu alvo faça um teste de resistência para resistir aos seus efeitos, o CD é igual a 8 + seu bônus de proficiência + seu modificador de Força ou Destreza (sua escolha).
- Se você já possui dados de superioridade, ganha mais um; caso contrário, você passa a ter um dado de superioridade, que é um d6. Esse dado é usado para alimentar suas manobras e é gasto quando utilizado. Você recupera o dado de superioridade gasto quando termina um descanso curto ou longo.
