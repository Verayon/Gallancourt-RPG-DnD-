# Armadura Leve

Seu treinamento lhe ensinou a se mover com desenvoltura mesmo vestindo uma armadura leve.

## Efeito

Você treinou para dominar o uso de armadura leve e ganha os seguintes benefícios:

- Aumente sua Força ou Destreza em 1 ponto, até o máximo de 20.
- Você ganha proficiência com armadura leve.
