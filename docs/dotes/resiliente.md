# Resiliente

Você treinou intensamente para resistir a um tipo específico de perigo, fortalecendo corpo e mente.

## Efeito

Escolha uma pontuação de habilidade. Você ganha os seguintes benefícios:

- Aumente a pontuação de habilidade escolhida em 1 ponto, até o máximo de 20.
- Você ganha proficiência em testes de resistência que usem a habilidade escolhida.
