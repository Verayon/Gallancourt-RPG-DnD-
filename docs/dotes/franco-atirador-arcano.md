# Franco-Atirador Arcano

Você aprendeu técnicas para aprimorar seus ataques com certos tipos de magias, estendendo seu alcance e precisão.

## Efeito

Você ganha os seguintes benefícios:

- Quando conjura uma magia que exige uma jogada de ataque, o alcance dessa magia é dobrado.
- Seus ataques de magia à distância ignoram cobertura parcial e cobertura de três quartos.
- Você aprende um truque que exige uma jogada de ataque, escolhido entre a lista de magias de bardo, bruxo, clérigo, druida, feiticeiro ou mago. Escolha um truque compatível com uma classe pela qual você tenha capacidade de conjuração. O truque é considerado uma magia dessa classe para você, mas não conta no número de truques que você conhece.
