# Sentinela

Você dominou técnicas para tirar proveito de qualquer brecha na guarda de um inimigo, impedindo-o de escapar.

## Efeito

Você ganha os seguintes benefícios:

- Quando você acerta uma criatura com um ataque de oportunidade, o deslocamento dela se torna 0 pelo restante do turno.
- Criaturas provocam um ataque de oportunidade de você mesmo que usem a ação Desengajar antes de deixar seu alcance.
- Quando uma criatura a até 1,5 metro de você faz um ataque contra um alvo que não seja você (e esse alvo não possua este dote), você pode usar sua reação para fazer um ataque corpo a corpo com arma contra a criatura atacante.
