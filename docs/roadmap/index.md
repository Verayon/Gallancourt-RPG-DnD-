# Roadmap

Tudo o que o site pretende implementar — o que ainda falta fazer. Cada item tem uma prioridade
(Alta/Média/Baixa), uma funcionalidade (a área que ele afeta: UI, Engine, Conteúdo, Infra ou
Dados) e, opcionalmente, um responsável (útil quando mais de um desenvolvedor estiver no
projeto). Leitura livre para qualquer um; em **🔑 Modo Mestre** (cabeçalho, ao lado do alternador
claro/escuro) os botões de adicionar, editar e excluir aparecem direto nesta página — sem precisar
do Painel.
