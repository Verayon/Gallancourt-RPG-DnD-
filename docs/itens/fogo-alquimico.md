# Fogo alquímico (frasco)

Substância viscosa que se inflama ao contato com o ar. Pode ser atirada como arma improvisada;
a criatura atingida sofre 1d4 de dano de fogo no início de cada um dos seus turnos até que
alguém apague o fogo.
