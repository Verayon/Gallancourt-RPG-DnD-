# Anel de carneiro

Este anel possui 3 cargas e recupera 1d3 cargas gastas todos os dias ao amanhecer. Enquanto
estiver usando o anel, você pode gastar 1 carga como uma ação para criar o espectro translúcido
de um carneiro com chifres e atacar uma criatura a até 18 metros de distância. Faça um ataque à
distância mágico: se acertar, o alvo sofre 2d10 de dano de concussão e, se for Grande ou menor,
pode ser empurrado até 3 metros para longe.

Se você gastar 2 ou 3 cargas de uma só vez no ataque, o dano e a distância de empurrão aumentam
proporcionalmente.
