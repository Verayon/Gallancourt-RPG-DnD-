# Kit de ladrão

Conjunto de limas, pinças, uma pequena serra e gazuas usado para arrombar fechaduras e
desarmar armadilhas. A proficiência soma o bônus de proficiência em testes de Destreza feitos
para abrir fechaduras ou desarmar mecanismos de armadilha.
