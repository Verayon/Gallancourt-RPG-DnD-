# Tribolos (saco com 20)

Espinhos de metal espalhados pelo chão em uma área de 1,5 metro. Uma criatura que entre nessa
área sem calçados protegidos sofre 1 de dano perfurante e tem seu deslocamento reduzido a 0
pelo resto do turno.
