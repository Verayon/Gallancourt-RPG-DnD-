# Bandolim de Canaith

Este é um dos sete Instrumentos dos Bardos, instrumentos musicais lendários imbuídos de magia
ancestral. Enquanto estiver sintonizado com ele, você pode usá-lo como um foco de conjuração para
suas magias de bardo e recebe vantagem em testes de Performance que envolvam tocá-lo.

O bandolim também permite que você gaste uma ação para conjurar, uma vez por dia cada, os feitiços
névoa nebulosa, invisibilidade (em você mesmo) ou línguas, sem precisar de componentes materiais.
