# Chapéu de disfarce

Enquanto estiver sintonizado com este chapéu e o estiver usando, você pode usar uma ação
para lançar o feitiço disfarce pessoal a partir dele, podendo ativá-lo quantas vezes
quiser, e encerrar o efeito antes do tempo como uma ação bônus.

Uma criatura que suspeite do disfarce e examine você de perto pode tentar um teste de
Inteligência (Investigação) contra CD 13 para perceber a ilusão.
