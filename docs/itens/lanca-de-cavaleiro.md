# Lança de cavaleiro

Arma marcial corpo a corpo. Projetada para combate montado; quando usada a pé, exige as duas
mãos (propriedade Especial). Além disso, impõe desvantagem ao atacar um alvo a 1,5 metro ou
menos de distância.
