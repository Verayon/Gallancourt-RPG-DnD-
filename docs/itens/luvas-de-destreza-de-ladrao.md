# Luvas de destreza de ladrão

Enquanto estiver usando estas luvas simples e cinzentas, você recebe um bônus de +5 em
testes de Destreza (Prestidigitação) e em testes de Destreza feitos para abrir fechaduras.

Além disso, outras criaturas têm desvantagem em testes de Sabedoria (Percepção) feitos para
notar que você está usando as mãos para furtar algo ou para forçar uma fechadura.
