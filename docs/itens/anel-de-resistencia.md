# Anel de resistência

Você possui resistência a um tipo de dano específico enquanto estiver usando este anel. O tipo de
dano é determinado no momento em que o anel é criado — ácido, concussão, cortante, elétrico, fogo,
frio, necrótico, perfurante, psíquico, radiante ou veneno.

Cada anel de resistência é feito para um tipo de dano diferente, e muitas vezes carrega gravuras
ou gemas que sugerem visualmente qual elemento ele domina.
