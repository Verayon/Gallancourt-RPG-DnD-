# Baralho do destino

Este baralho de cartas ilustradas, geralmente composto por 22 lâminas distintas, contém um poder
imprevisível e perigoso. Você pode usar uma ação para retirar uma ou mais cartas do baralho e,
imediatamente ao fazer isso, sofre o efeito mágico gravado naquela carta — que pode variar de uma
dádiva extraordinária, como riqueza ou um aumento permanente de atributo, até uma desgraça
terrível, como o envelhecimento repentino, uma maldição ou até mesmo ser sugado para outro plano
de existência.

Depois que uma carta é retirada, ela desaparece do baralho, a menos que algum efeito a devolva. Se
o baralho tiver menos de 20 cartas quando alguém o usa, há uma chance de o próprio baralho sumir em
uma explosão de fumaça colorida, levando consigo quem o puxou.
