# Cinto de força do gigante das colinas

Enquanto estiver vestindo este cinto, sua pontuação de Força passa a ser 21. Isso não tem efeito
algum se sua Força já for 21 ou mais sem o cinto.

Cintos semelhantes existem para outros tipos de gigantes, cada um conferindo uma pontuação de
Força ainda maior conforme a raridade do item aumenta.
