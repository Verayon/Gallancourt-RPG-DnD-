# Anel de invisibilidade

Enquanto estiver usando este anel, você pode usar uma ação para tornar a si mesmo invisível. Tudo
o que você estiver vestindo ou carregando fica invisível junto com você. Esse efeito dura até você
usar uma ação bônus para encerrá-lo ou até você fazer uma jogada de ataque, causar dano ou
conjurar uma magia.

Algumas versões malditas deste anel existem, que impedem seu usuário de remover o anel e o
transportam periodicamente para o Plano Astral assim que ele é colocado, sem aviso algum.
