# Corda animada

Esta corda de 18 metros de comprimento obedece a comandos mentais simples ditos em voz alta
por quem a segura, podendo se mover, se enrolar, se desenrolar, se amarrar em um ponto
firme ou se desatar sozinha a uma velocidade de 3 metros por rodada.

Ela suporta até 1.350 quilos antes de se romper, e pode ser comandada para se tornar rígida
como uma vara ou flexível como uma corda comum, facilitando escaladas e resgates.
