# Dulcimer

Instrumento de cordas percutidas, tocado com pequenos martelos sobre as cordas estendidas em
uma caixa de madeira. A proficiência soma o bônus de proficiência em testes de Carisma
(Apresentação) ao tocar o instrumento.
