# Botas de levitação

Enquanto estiver usando estas botas, você pode usar uma ação para conjurar nelas mesmo o efeito do
feitiço levitação, que dura até você usar outra ação para encerrá-lo.

O efeito funciona exatamente como o feitiço: você flutua no ar sem a necessidade de concentração
e pode se mover apenas para cima, para baixo ou lateralmente ao se empurrar contra uma superfície
ou objeto fixo próximo.
