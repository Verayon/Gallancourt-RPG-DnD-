# Ferramentas de serralheiro

Pequenas ferramentas de precisão usadas para montar e reparar engenhocas mecânicas simples,
como fechaduras, armadilhas e pequenos dispositivos de metal. A proficiência soma o bônus de
proficiência em testes de Destreza para construir ou consertar esses mecanismos.
