# Cota de malha reforçada

Armadura média composta por centenas de pequenos anéis de metal entrelaçados, vestida sob as
roupas comuns. CA 13 + modificador de Destreza (máximo de 2). É discreta o bastante para não
impor desvantagem em testes de Destreza (Furtividade).
