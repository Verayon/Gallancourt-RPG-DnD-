# Passo Distante

O espaço entre um ponto e outro se dobra brevemente a cada passo que você dá, permitindo saltos instantâneos através do campo de batalha.

- **Nível:** 5º
- **Escola:** Conjuração
- **Tempo de conjuração:** 1 ação bônus
- **Alcance:** Pessoal
- **Componentes:** V
- **Duração:** Concentração, até 1 minuto
- **Classes:** Feiticeiro, Bruxo, Mago

## Efeito

Você se teleporta instantaneamente até 18 metros para um espaço desocupado que possa ver. Enquanto a magia durar, você pode usar uma ação bônus em cada um dos seus turnos subsequentes para repetir esse salto, até a magia terminar.

**Em níveis superiores.** Esta magia não possui escalonamento para espaços de magia superiores.
