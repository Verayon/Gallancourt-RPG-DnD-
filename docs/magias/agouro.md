# Agouro

Lançando pequenos ossos, varetas ou outros objetos sagrados de adivinhação, você busca um
vislumbre de como um curso de ação se desenrolará.

- **Nível:** 2º
- **Escola:** Adivinhação
- **Tempo de conjuração:** 1 minuto
- **Alcance:** Pessoal
- **Componentes:** V, S, M
- **Duração:** Instantânea
- **Classes:** Clérigo

## Efeito

Você consulta um presságio sobre o resultado provável de uma ação específica que pretende realizar
dentro da próxima meia hora. Forças além da compreensão comum respondem com uma indicação geral:
favorável, desfavorável, uma mistura das duas ou nenhuma indicação clara quando o resultado é
demasiado incerto para ser previsto. Repetir a consulta para a mesma decisão sem que as
circunstâncias mudem torna a resposta cada vez menos confiável.
