# Dispersão

Com uma única palavra, você arranca várias criaturas do local onde estão e as espalha instantaneamente pela área, longe umas das outras.

- **Nível:** 6º
- **Escola:** Conjuração
- **Tempo de conjuração:** 1 ação
- **Alcance:** 9 metros
- **Componentes:** V
- **Duração:** Instantânea
- **Classes:** Feiticeiro, Bruxo, Mago

## Efeito

Você escolhe até cinco criaturas que possa ver dentro do alcance. Cada uma que não queira ser movida pode fazer um teste de resistência de Sabedoria para resistir. As criaturas afetadas são teleportadas instantaneamente para um espaço desocupado que você possa ver a até 36 metros de você, com cada criatura sendo enviada para um local diferente.

**Em níveis superiores.** Esta magia não possui escalonamento para espaços de magia superiores.
